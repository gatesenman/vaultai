VaultAI Tools 1.8.0 — 安装说明 / Install notes
==============================================

【安装版 · 首选】VaultAI-Setup-1.8.0.exe  (NSIS)
  双击后按向导安装，会创建开始菜单和桌面快捷方式，可在「应用和功能」中卸载。
  静默安装：VaultAI-Setup-1.8.0.exe /S
  注意：安装程序会关闭正在运行的 VaultAI.exe（包括便携版）。

【安装版 · 备选】VaultAI-Setup-1.8.0-win-x64.zip
  1. 解压 zip
  2. 双击 VaultAI-Setup.bat（或 Install-VaultAI.ps1）
  3. 程序安装到 %LOCALAPPDATA%\VaultAI，并创建快捷方式和「应用和功能」卸载项

【便携版】VaultAI-Setup-1.8.0-Portable.exe
  双击即可运行，不安装任何东西。

【源码】VaultAI-src.zip → 见 BUILD.md

从 1.3.x / 1.4.0 升级：
  直接覆盖安装，用原来的主密码解锁。
  解锁时会先把原始加密文件复制到 %APPDATA%\VaultAI\pre-1.8.0-backup\，再迁移数据。
  首页会列出所有变化，例如：
    · Linear / Sentry / Slack 已转为「通用 HTTP」预设，密钥和权限不变；
    · Gmail「草稿」权限降为「只读」；
    · 网页抓取工具和 Demo 已移除；
    · 文件夹已转为标签。
  不会丢弃任何密钥。如需回退到 1.4.0，请先恢复 pre-1.8.0-backup 中的两个文件。

首次打开：
  1. 设置主密码（无法找回，请务必记下）。锁屏页右上角可以切换 中文 / English。
  2. 按首页「快速开始」的 4 步操作：
       添加第一个凭据 → 连接 AI 助手（复制生成的配置）→ 重启 AI 应用 → 验证连接
  3. 「停用所有 AI」按钮在标题栏，出现问题时可以一键停用全部 AI 助手。

访问权限（所有连接相同）：关闭 · 只读 · 写入 · 完全
剪贴板：复制的密码默认 30 秒后自动清除（设置 → 安全）
命令行生成密码：vaultai gen / vaultai gen passphrase --words 6
MCP：http://127.0.0.1:3847/mcp，请求头 Authorization: Bearer <访问令牌>
     （「AI 助手 → 配置」会给出各客户端可直接粘贴的配置）

测试：Linux E2E 122/0 通过；Windows 真机 69/0 通过（详见 E2E测试报告.md）。

## 1.8.0 人用自动填充

在任意应用账号框输入时，按 `Ctrl+Shift+P`（或输入触发词 `pp`）在光标旁弹出小浮框，按用户名/网站匹配保险库条目并填入；继续打字过滤，↑↓ / Enter / Tab / 1–6 / Esc。详见 `docs/AUTOFILL.md`。与 AI/MCP 密码权限（关/只读/完全）相互独立。


【1.8.0 新增】
  · 后台快速新建快捷键：默认 Ctrl+Shift+N，浮动面板（与自动填充 Ctrl+Shift+P、应用内 Ctrl+N 不同）
  · 数据库存储（不是备份）：设置 → 数据库，连接 SQLite / PostgreSQL / MySQL，启用「将密码存到数据库」
    密码增删改查直接写入 VaultAI 表；默认用保险库主密钥 AES-256-GCM 加密密码/用户名/备注。详见 docs/DB-STORAGE.md
