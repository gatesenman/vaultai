# VaultAI Tools 1.5.0 产品评审与功能收敛

> 角色：资深产品经理 · 评审对象：1.4.0 · 结论落地版本：1.5.0
> 原则：**少而可信**。每个保留的功能必须真实可用、可测试、名字一致；做了一半或只能在 mock 上跑的功能，要么做诚实，要么删掉。

## 1. 定位

**VaultAI 是一个本地加密保险库，让 AI 助手安全地使用你的凭据。**

- AI 助手（Claude Desktop、Cursor、Claude Code、命令行）通过 MCP / CLI 调用你连接好的服务（GitHub、Notion、Stripe、任意 HTTP API…）。
- 密钥**永不交给 AI**：VaultAI 代替 AI 发请求，按「每个 AI × 每个连接」的权限、每日限额、有效期执行，全部记录到活动日志，并提供**一键停用所有 AI**。
- 同时是一个**个人密码管理器**（条目、生成器、安全检查）。
- 中文 / English 双语是核心能力，默认中文。

**目标用户**：在 Windows 上使用 Claude Desktop、Cursor 等 AI 工具的个人开发者 / 知识工作者。不是团队产品，不是浏览器插件，不做云同步。

**判断标准**：这个功能是否帮助用户 ① 把凭据安全地交给 AI 使用，② 看清并控制 AI 做了什么，③ 管理自己的密码？三者都不是 → 移除或藏到高级。

## 2. 1.4.0 存在的主要问题

| # | 问题 | 影响 |
|---|------|------|
| P1 | 侧边栏 10 项（应用、密码、生成器、安全、助手、权限、限额、活动、连接 AI、设置），同一件事分散在 3–4 个页面 | 新用户找不到下一步 |
| P2 | 没有首次引导：创建保险库后落到空的「应用」页，不知道怎样把 AI 接上 | 核心价值走不通 |
| P3 | 没有总览：看不到「AI 现在能访问什么、今天做了什么」 | 用户失去控制感 |

| P5 | 权限等级不统一：Gmail 有「草稿 / 管理」，日历只有「只读 / 完全」，其余是「只读 / 写入 / 完全」 | 用户无法形成稳定心智 |

| P9 | Google OAuth 回调页把 `error` 参数原样写进 HTML | **安全漏洞：本机来源上的反射型 XSS**，可在解锁状态下读取保险库 |
| P10 | 「令牌只显示一次」与旁边的「显示令牌」按钮矛盾；「之后可以续期」但没有续期入口 | 文案不诚实 |
| P11 | 可以选择 ChatGPT 作为客户端，但 ChatGPT 无法连接本机 MCP | 误导 |
| P12 | 托盘图标为空（看不见），窗口关闭后隐藏到托盘 → 用户找不到也退不出 | 桌面端缺陷 |
| P13 | stdio 桥对 MCP 通知（无 id）也回包；HTTP `/mcp` 对通知回 200、对 SSE GET 回 200 | 协议不合规，个别客户端会报错 |
| P14 | 每次修改权限都弹 toast；导入备份连续确认两次 | 打扰 |
| P15 | 活动表格部分英文写死；i18n 依赖「英文短语替换层」 | 双语不一致 |
| P16 | 「关于」写着「灵感来自 GBrain Tools」 | 与产品无关 |

## 5. 新增功能

1. **首次引导（首页清单，4 步）**：① 创建保险库 ✓ → ② 添加第一个凭据（连接或密码）→ ③ 连接 AI 助手（选客户端 → 生成可复制的 Claude Desktop / Cursor / Claude Code 配置）→ ④ 验证连接（等待 AI 第一次调用 MCP，显示「已连接」）。完成或手动隐藏后不再出现。
2. **首页总览**：AI 现在能访问什么（每个 AI × 非关闭的连接，含有效期）、今天的成功/被拒绝次数与最近 5 条、密码安全评分、迁移说明。
3. **一键停用所有 AI**：标题栏常驻 + 首页按钮；立即停用所有 AI 助手的令牌、写入活动日志；之后逐个重新启用。
4. **空状态**：每个列表为空时给出一句话说明 + 一个主操作。
5. **编辑连接**：改名、轮换密钥、补充 Base URL，权限保持不变。
6. **续期**与**最近连接时间**。
7. **术语统一**：单一 i18n 键值文件（删除英文短语替换层），并遵守下表。

## 6. 数据兼容与迁移

- 1.3.x / 1.4.0 保险库**必须能直接打开**。迁移在解锁时执行一次（`schemaVersion` 1 → 2），幂等。
- **迁移前**把原始加密文件原样复制到数据目录下的 `pre-1.5.0-backup/`（仍由原主密码加密）。
- Linear / Sentry / Slack → 原地转为通用 HTTP 预设，**保留 ID、加密密钥、各 AI 的权限等级**。
- Web 抓取、Demo（非开发模式）→ 删除内置记录及其权限（无用户密钥）；若曾授予过权限，写迁移说明。
- Gmail「草稿」→ 只读（只降不升，写说明）；「管理」→ 写入。
- 客户端 ChatGPT → 其他（写说明）。
- 文件夹 → 标签（写说明）。
- 已删除工具的每日限额规则被清理；若曾自定义过数值，写说明。
- `allowNonLoopback` 设置删除（从未生效）。
- 所有迁移说明保存在保险库内，首页展示，可逐条关闭。**不会静默丢弃任何用户密钥。**
- 1.5.0 保险库不支持降级回 1.4.0 打开（如需回退，使用 `pre-1.5.0-backup/`）。
